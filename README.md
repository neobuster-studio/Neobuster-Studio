# Neobuster Studio

An independent mobile app studio from Vietnam, making simple, fast and reliable Android apps for everyday life.

## 🎯 What we aim for

- **Simple:** apps anyone can pick up and use in seconds, with no learning curve.
- **Fast and light:** smooth on budget phones as well as flagships, and gentle on battery and storage.
- **Privacy first:** we collect only the data an app needs to work, and we explain clearly why we ask for each permission.
- **Useful every day:** small tools that save time on everyday tasks, like managing money, organizing notes and making smarter choices with on-device AI.
- **Built to last:** careful testing before every release, and regular updates based on user feedback.

## 🛠 Tech

Kotlin · Jetpack Compose · Flutter · Firebase · On-device AI
